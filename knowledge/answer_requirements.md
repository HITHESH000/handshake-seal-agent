# Answer Requirements

## Accuracy

* The answer must be factually correct and verifiable against primary sources.


* Exactly one correct answer must be provided, with no reasonable alternative entity or candidate fitting all constraints in the prompt.


* The answer must be unambiguous and hold up against primary sources with no contradicting information in another comparable source.


* Every factual statement and premise in the prompt tied to the answer must be entirely true.



## Sources

* The answer must be supported by primary or official sources (e.g., official records, peer-reviewed work, original documents).


* The answer must be read directly from a live, accessible web page.


* Prohibited sources for key or decisive verification include:
* Archive.org 


* Wikipedia for key/decisive verification 


* Audio or video content (e.g., YouTube, Spotify; facts must be text-extractable or OCR-able) 


* Search-engine result pages or spatial-only Google Maps/Street View 


* User-generated forums as the sole source for a factual claim 


* Cached snapshots when the live page contradicts them 


* Paywalled sources that reviewers cannot access 





## Verification

* Contributors must verify the answer themselves by tracing it backward through the web before constructing or submitting the task.


* The answer must be printed somewhere you can point to—you must be able to open one trustworthy page and highlight the exact answer in plain text with your mouse.


* The answer must never be calculated, added up, or worked out in your head; any final numeric answer must be read straight off the page .



## Formatting

* The answer must be provided as a single, short string representing a specific entity.


* Allowed entity types include:
* Name 


* Place 


* Date 


* Number 


* Title 


* Event 




* Long-form, explanatory, or paragraph answers are strictly prohibited.


* Answer formatting (e.g., date structure) must be clean and consistent with the cited primary source.



## Common Mistakes

* Writing explanatory text, summaries, or paragraphs instead of picking a single entity and stating it plainly.


* Doing the math or calculating values for the AI/task instead of reading the printed answer directly off the page.


* Using a wrong reference answer, which invalidates the answer, the golden trajectory, and every model-failure block at once.


* Mismatched numbers, figures, or URLs between the answer, golden trajectory steps, and source list.


* Selecting an answer that has multiple plausible/defensible candidate entities or contradicting sources.


* Relying on non-primary, paywalled, cached, or prohibited sources (such as Wikipedia) for key verification .
