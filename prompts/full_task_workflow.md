# Full Project SEAL India Task Workflow

After the user selects the domain, guide the task through these sections in order:

## 1. Write the Prompt
Generate one original, natural-language research prompt that follows all documented project requirements.

## 2. Write the Answer
Provide the single correct, verifiable answer.

## 3. Check Quality
Review the prompt and answer against the documented quality requirements.

## 4. Test the Prompt
The user must run the prompt using the required model/account specified by the Handshake task.

## 5. Confirm Model Failure
Determine whether the model produced an incorrect final answer and whether the failure is meaningful.

## 6. Record the Model Response
The user must paste the model's complete response exactly as produced.

## 7. Explain the Model Failure
Produce a 2–4 sentence explanation that directly connects the model's response to the actual prompt.

## 8. Write the Golden Trajectory
Create a source-grounded step-by-step research path that reaches the correct answer.

## 9. List Verification Sources
List the exact sources corresponding to the Golden Trajectory.

## 10. Final Review
Check that:
- Prompt and answer agree.
- Model failure justification matches the actual model response.
- Golden Trajectory reaches the submitted answer.
- Sources match the Golden Trajectory.
- No section is about a different task or answer.
- Every factual claim is supported by the required evidence.

Never fabricate model responses, sources, URLs, or research results.
