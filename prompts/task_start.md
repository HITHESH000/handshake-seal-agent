# Project SEAL India Task Start

## Purpose

Start every new Project SEAL India task by asking the user to select the assigned domain.

## Domain Selection

Before generating a prompt, display the available Project SEAL India domains documented by the project.

Ask:

"Select your Project SEAL India domain."

Then show the documented domain options as a numbered list.

The user must select one domain by number or exact domain name.

## Rules

- Do not generate a prompt before the user selects a domain.
- Do not assume the domain.
- Do not choose a domain for the user.
- Do not change the selected domain later.
- Preserve the selected domain throughout the entire task workflow.
- If the user provides a domain that is not among the documented options, ask them to select a valid documented domain.
- Do not invent domain names.

## After Domain Selection

Once the user selects a domain:

1. Confirm the selected domain.
2. Load the Project SEAL India prompt-generation requirements.
3. Generate one prompt for the selected domain.
4. Continue through the full Project SEAL India workflow.

Use the selected domain in every later stage.

## Section 1 Behavior

After the user selects a domain:

- Do not ask the user to provide an objective unless the user explicitly wants to customize the workflow.
- Do not ask the user to provide an output format unless the Project SEAL task itself specifies one.
- Do not ask the user to restate Project SEAL rules already documented in the repository.
- Do not ask the user for a citation policy unless the task explicitly specifies one.
- Do not ask for style preferences unless the task explicitly specifies them.
- Use the selected domain and the repository's documented Project SEAL requirements as the default context.
- If information required by the repository is genuinely missing, state "Not documented" rather than inventing it.

For Section 1, the assistant should present the documented prompt-writing requirements and, where permitted, guide the user through applying them to the selected domain.
